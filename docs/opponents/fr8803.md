# FR8803/JassOpenAIGym: TF-Agents DQN (bachelor thesis, 2021)

## What it is

- `github.com/FR8803/JassOpenAIGym`. **No licence file**, so it runs locally as an opponent only, in
  its own venv and process.
- An OpenAI-gym Schieber (`gym_Jass`, its own engine: suit trumps, Obenabe, Undenufe, shoving) and a
  TF-Agents DQN trained on a Colab TPU for 500,000 steps (`Jass_RL.ipynb`). Five trained policies,
  one per reward scheme: `Data_BA/{Game,Round,Trick,Hybrid,Hybrid random}/rl_jass`. They are in
  **Git LFS**; the anonymous clone gets pointers, and the real files come from
  `media.githubusercontent.com` (below).
- Training partners and opponents: random players, plus one "best card by points" opponent
  (`strategy = "Mixed"`).

## What the trained policy can actually do

The network has **8 outputs and no action mask** (`action_space = spaces.Discrete(8)`), but the
env's action IDs are 0–35 for cards and 36–42 for trumps. Their `_decode_action` plays the chosen ID
if it is legal and otherwise **a uniformly random legal action**. So the net can only ever name
deck cards 0–7, which are Schellen A K Q J 10 9 8 7 (our ♦A…♦7). Every other card it plays, and
every trump choice it makes, is random. That is a training-setup flaw, not something the
adapter introduces: the policy is close to a random player that prefers to play a diamond when
it is allowed one. Expect our bot to win by a margin close to its margin over random.

## How it is seated

`arena/opponents/servers/fr8803_server.py` (venv `venvs/tf`: `tensorflow-cpu` 2.21 and numpy):

- **Network.** Read from the checkpoint variables and run as the TF-Agents `QNetwork` it was built
  as: flatten 5×4×9 = 180 → Dense 128 ReLU → Dense 36 ReLU → Dense 8. Their `saved_model.pb` needs
  tf-agents' type registrations to load (`_TFPTypeSpec`), and the variables are the same weights.
- **Observation.** Built with their own `encode_cards` / `encode_stich`, as their
  `_extract_observation` does: the hand, the current trick, the round's earlier tricks, the legal
  cards, and the trump plane.
- **Action.** Argmax over the eight Q-values, played if it is a legal card, otherwise a seeded random
  legal card (their `_decode_action`). Trump is uniformly random over their legal trump actions:
  seven from forehand (the six contracts and "Gschobe", the shove), six from the shoved-to partner.
- **Cards.** Their deck order is Schellen/Rosen/Schilten/Eichel × A…6, which is our index with
  D/H/S/C = Schellen/Rosen/Schilten/Eichel. Their seats are ours (0&2 against 1&3, play order +1).

## How to run it

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/FR8803/JassOpenAIGym /home/user/ext/FR8803_JassOpenAIGym
cd /home/user/ext/FR8803_JassOpenAIGym && git lfs ls-files -n | while IFS= read -r f; do
  curl -sSL -o "$f" "https://media.githubusercontent.com/media/FR8803/JassOpenAIGym/main/$(python3 -c 'import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))' "$f")"; done
python3 -m venv /home/user/ext/venvs/tf && /home/user/ext/venvs/tf/bin/pip install tensorflow-cpu numpy
cd /home/user/krass-jass
python -m arena.opponents.match fr8803 --deals 2 --workers 2            # smoke
python -m arena.opponents.match fr8803 --deals 400 --seed 1             # "Game" model
python -m arena.opponents.match fr8803:Round --deals 100 --seed 1       # another reward scheme
```
